## 2.2. Methodology

 ### (1) 데이터셋의 핵심 특성(Feature Characteristics)
#### ① 범주형 변수 중심의 정형 데이터  
성별, 연령대, 거주 도시 등 사용자의 인구통계학적 집단을 나타내는 범주형 데이터가 주를 이룬다.  

#### ② 정보의 마스킹(Masking) 처리  
직업 코드 및 상품 카테고리가 실제 명칭 대신 ‘0~20’ 사이의 무의미한 숫자로 가려져 있어, 인간의 도메인 지식을 직접 적용하기 어렵고 데이터 자체의 패턴에만 의존해야 하는 제약이 있다.

<br>
<br>


### (2) 아키텍처별 특성과 선정 이유
본 프로젝트에서는 머신러닝(ML) 구현을 위한 라이브러리로 ‘Scikit-learn’을 채택하여 ‘Random Forest’와 ‘HistGB’ 아키텍처를 구축하였으며, 딥러닝(DL) 구현을 위해서는 ‘PyTorch’ 라이브러리를 기반으로 ‘Deep DNN’과 ‘Wide NN’ 아키텍처를 설계하여 상호 대조 실험을 진행하였다.  
<br>

#### ① Random Forest (머신러닝)  
* **특성**: 수백 개의 **'결정 트리(Decision Tree)'** 를 각기 다른 데이터 샘플로 학습시킨 뒤, 그 결과들의 평균(회귀)이나 다수결(분류)로 최종 답을 내는 '앙상블(Ensemble)' 모델이다. 데이터에 이상치나 불필요한 노이즈가 많을 때 강력한 방어력을 가지며, 하이퍼파라미터 튜닝 없이도 매우 안정적인 성능을 보장하는 환경에서 필수적으로 선택된다.  
* **선정 이유**: 본 프로젝트에서 머신러닝과 딥러닝 아키텍처 간의 예측 정확도를 객관적으로 비교·대조하기 위해, 가장 전통적이고 안정적인 머신러닝 알고리즘인 Random Forest를 **실험적 대조군**으로 선정하였다. 특히, 본 데이터셋처럼 무의미한 숫자 코드로 마스킹된 변수들은 일반적인 선형 모델의 연산을 쉽게 교란시키곤 한다. 반면 Random Forest는 피처의 스케일이나 왜곡에 영향을 받지 않고 예측을 수행할 수 있다. 따라서 **데이터 노이즈에 흔들리지 않는 신뢰성 높은 **예측 기준점(Baseline)** 을 구축하기 위해 필수적인 축으로 연관 설계하였다.  

#### ② HistGB (Histogram-based Gradient Boosting, 머신러닝)  
* **특성**: 입력 데이터를 **구간(Histogram)** 으로 나누어 처리하여 학습 속도를 획기적으로 높인 **Gradient Boosting 모델**로, **이전 트리의 오차를 다음 트리가 보완**하며 학습하는 방식이다. 데이터의 양이 수십만 건 이상으로 거대하고, 학습 및 예측 속도가 최우선으로 요구되는 대규모 정형 데이터 분석 환경에서 가장 선호되는 방식이다.  
* **선정 이유**: 머신러닝 기초 대조군으로 설정한 Random Forest의 한계를 극복하고 성능을 한 단계 더 끌어올린 **고도화된 발전형 모델**로서 채택하였다. 대규모 블랙프라이데이 매출 데이터 안에서 '성별, 나이, 도시'라는 수많은 범주형 변수를 가장 빠르고 정확하게 분기(Split)할 수 있는 최적의 알고리즘으로, 오차를 줄여나가는 부스팅 구조를 통해  **머신러닝 자율 최적화 환경에서의 한계 성능**을 도출하고자 채택하였다.

#### ③ PyTorch Deep DNN (Deep Neural Network, 딥러닝)  
* **특성**: 입력층과 출력층 사이에 **은닉층(Hidden Layer)을 여러 층 깊게(Deep) 쌓아 올려** 데이터의 복잡하고 추상적인 특징을 찾아내는 방식이다. 레이어가 깊을수록 **데이터 사이의 아주 미묘하고 복잡한 상관관계를 스스로 찾아내고 학습**한다. 
* **선정 이유**: 딥러닝의 성능을 측정하기 위한 기본적인 비교군으로서 본 아키텍처를 채택하였다. "특정 지역에 거주하는 특정 연령대의 직장인"처럼 인구통계학적 변수들이 다각도로 결합하여 발생하는 복잡한 소비 메커니즘을 모델 스스로 추론하도록 유도했다. 사람이 직접 규칙을 짜줄 수 없는 마스킹 데이터 환경에서, 딥러닝 고유의 **엔드투엔드(End-to-End) 패턴 추출 능력**을 검증하기 위해 채택하였다.

#### ④ PyTorch Wide NN (Wide Neural Network, 딥러닝)  
* **특성**: 은닉층을 깊게 쌓아 학습하는 DNN과 달리, 단일 층 내에 **뉴런의 폭(Width)을 넓게 배치**하는 방식이다. 각 변수들의 직접적인 영향력을 효과적으로 학습하여 ‘Wide & Deep’ 모델의 한 축을 담당하고 있으며, 특정 데이터 조합이 정답에 미치는 영향력을 **선형적으로 직접 기억하는데 특화**된 아키텍처이다.
* **선정 이유**: 기초 비교군인 Deep DNN의 구조와 비교하기 위해, **직관적인 규칙 기억에 특화된 딥러닝 모델**로서 채택하였다. 깊은 단계로 추론하는 Deep DNN 구조와 상반된 매커니즘을 적용함으로써, **'기억(Wide)과 추론(Deep)'의 구조적 차이가 마스킹 데이터셋 환경에서 어떻게 다르게 반응하는지** 상호 대조하기 위해 배치하였다.

### [실험 1] 아키텍처별 자율 최적화 학습 성능 대조 (`code_1`)

* **실험 목적**: 각 인공지능 모델이 주어진 하이퍼파라미터 환경 내에서 스스로 변수별 가중치(Feature Importance)를 최적화하여 도달할 수 있는 최종 예측 성능을 대조한다.
* **성능 지표**: $R^2$ Score(데이터 설명력, 높을수록 우수), RMSE(평균 예측 오차, 낮을수록 우수), Time(효율성 및 비용, 낮을수록 우수)

$R^2$ Score의 정의는 다음과 같다.

$\(R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2} = 1 - \frac{SSE}{SST}\)$

\(y_{i}\) : 실제 관측값\
(\^{y}_{i}\) : 모델의 예측값
ȳ : 실제값들의 평균
SSE(오차제곱합) : 실제값과 예측값 차이의 제곱 합
SST(총제곱합) : 실제값과 평균값 차이의 제곱 합

RMSE의 정의는 다음과 같다.

$(RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2}\)$

$\(n\)$ : 데이터의 개수
$(y_{i}\)$ : 실제값 
 $(\^{y_{i}}\)$ : 예측값

Deep DNN은 128→64→32→1로 레이어가 4개이고. 각 레이어마다 행렬 곱셈 + 배치 정규화 + 활성화 함수를 n(프로그램에서 n=30) 에폭(전체 학습 데이터셋을 모델이 처음부터 끝까지 완전히 한 번 학습하는 과정) × 여러 배치만큼 반복한. 레이어가 많을수록 순전파와 역전파연산량이 누적되어 가장 오래 걸렸다. 또한 Wide NN과 Hist GB에서 HistGB는 "트리 개수(150개) × 직렬 순차"의 연산을 해야 해서 느리고, WideNN은 "512차원 행렬 연산 × 30에폭"연산을 해야 하는 각자 다른 이유로 0.6초대에 수렴한 것이다. Random Forest는 여러개의 트리를 한번에 학습하기 때문에 속도가 제일 빠르게 나왔다.

* **분석결과① 전통적 머신러닝 모델(Random Forest, HistGB)의 성능 상승**
  * **현상**: `City_Category` 위주로 피처를 제한했을 때, Random Forest는 $R^2$ Score가 **9.71%에서 13.66%로**, HistGB(LightGBM형)는 **14.79%에서 13.69%로(오차 단축 및 전반적 안정화)** 데이터 설명력이 오히려 상승하거나 유지되는 경향을 보였다. 
  * **원인 분석**: 트리(Tree) 기반의 ML 모델은 고차원의 복잡한 데이터보다 패턴이 명확하고 단순한 변수가 주어졌을 때 Overfitting이 방지되는 특성이 있다. `City_Category`라는 명확한 지리적 경계 지표가 스크리닝 역할을 하여, 노이즈가 줄어든 상태에서 트리 분기가 더 유의미하게 이루어진 것으로 판단되었다.

* **분석결과② 딥러닝 모델(PyTorch Deep DNN, Wide NN)의 성능 하락**
  * **현상**: 종합 학습 조건에서 17.15%로 가장 높은 설명력을 보였던 PyTorch Deep DNN은 변수 고정 시 **12.97%로 급격히 하락**했으며, Wide NN 역시 **16.49%에서 13.35%로** 성능이 크게 감소하였다. 
  * **원인 분석**: 인공신경망(DNN) 구조는 수많은 변수 간의 복잡한 비선형적 상호작용을 스스로 학습하며 거대한 가중치 공간을 형성할 때 진가를 발휘한다. 그러나 입력 피처를 하나의 도메인(`City_Category`)으로 극단적으로 제한하자, 신경망이 학습할 수 있는 정보의 총량이 부족해져 표현력을 잃고 성능이 저하된 것으로 해석되었다.

추가로 해당 가중치를 100으로 고정하니 다른 모델들의 시간에는 큰 차이가 없었지만 HistGB 모델에서만 시간이 약 74% 감소하였다. City_Category만 남기고 나머지를 0으로 만들면 데이터가 사실상 3가지 값(A/B/C 인코딩)만 반복됩니다. HistGB는 트리를 만들 때 각 변수의 분기점(split point)을 탐색하는데, 입력 다양성이 극단적으로 줄어들면 분기 탐색이 매우 빨리 끝납니다. 원래 9개의 분기점에서 각 요소마다 A/B/C 인코딩을 해야 하지만 한 수치를 100으로 고정하니 8개의 수치의 값을 A로 고정하기 때문에 계산의 양이 감소하였기 때문이다.
반면 Wide NN 과 DNN은 각 단계마다 실행 시간에 큰 차이를 보이지 않았다. 딥러닝 연산에서 행렬 연산은 입력값 내용과 무관하기에 시간에서 차이를 보이지 않고 Random Forest는 이미 병렬 연산을 하기에 입력값에 큰 영향을 받지 않았기 때문이다.

### (1) 데이터셋 변경 ①
본 프로젝트는 초기에 [Retail Black Friday Sales 데이터셋](https://www.kaggle.com/datasets/noopurbhatt/retail-black-friday-sales-dataset)을 활용하여 '평상시'와 '블랙프라이데이' 시즌 간의 소비자 행동 변화를 비교 분석하고자 하였다. 그러나 초기데이터 탐색 및 시각화 과정에서 기존 데이터셋의 한계점을 발견하여 프로젝트 방향을 수정하게 되었다.

## 3.2. Discussion  
본 프로젝트는 고객의 인구통계학적 특성에 따른 블랙프라이데이 소비 금액을 예측하기 위해 머신러닝(ML)과 딥러닝(DL)을 아우르는 4개의 아키텍처를 다각도로 설계하고, 3가지 시나리오 실험을 통해 다음과 같은 최종 결론을 도출하였다.
